Plataforma de gestión de tesis

Buen día apreciados estudiantes, esperamos que se encuentren muy bien.

Con el objetivo de realizar la entrega de documentos finales a la biblioteca una vez se haya finalizado el proceso de entrega, revisión y aprobación de trabajos, proyectos de grado o tesis, requerimos de tu apoyo actualizando los datos personales dentro del sistema de gestión de trabajos de grado y tesis (https://eiee.tesisunivalle.co/).

Para realizar este proceso ingresa al sistema y diligencia el formulario de "Actualizar datos personales". Tener en cuenta incluir la firma como imagen (se requiere para incluir en el formato de autorización de publicación).
